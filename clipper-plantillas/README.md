# Catálogo de plantillas de Clipper

Clipper baja de aquí, solo, el paquete de plantillas de cada juego cuando lo reconoce.

## Cómo agregar o actualizar un juego

1. En Clipper: **Juegos > Exportar paquete**. Te deja `<Juego> plantillas.zip` en el escritorio.
2. Aquí en GitHub entra a la carpeta **paquetes**, dale **Add file > Upload files** y arrastra el .zip.
3. Dale **Commit changes**. En unas horas (o con "Buscar de nuevo" en Clipper) todos lo tienen.

Si subes un .zip con el mismo nombre, reemplaza al anterior y Clipper lo actualiza (sin borrar lo que cada usuario ya tenía).

## Aportes de los usuarios

Los usuarios usan **Juegos > Compartir** en Clipper: se abre una propuesta (Issue) aquí con el .zip. Revísalo y, si está bien, súbelo a **paquetes**.
